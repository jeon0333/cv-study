# 컴퓨터 비전 학습 로드맵

> **주의:** 아래 순서는 이 사이트의 임시 학습 경로입니다. Gemini가 만든 **원래 로드맵은 아직 전달받지 않았기 때문에** 해당 로드맵을 재현했다고 주장하지 않습니다. 원문을 보내 주면 순서와 단원을 그대로 반영할 수 있습니다.

## 현재 시작점: CNN 계열의 핵심 아이디어

| 순서 | 학습할 주제 | 핵심 질문 | 상태 |
|---|---|---|---|
| 00 | CNN / 역전파 기초 | convolution과 gradient는 무엇인가? | 학습 자료 준비됨 |
| **01** | **ResNet (2015/2016)** | 깊은 신경망은 어떻게 안정적으로 학습할까? | **첫 단원 완성** |
| 02 | DenseNet | 특성(feature)을 서로 어떻게 재사용할까? | 향후 작성 예정 |
| 03 | U-Net | 픽셀마다 예측하는 구조는 어떻게 만들까? | 향후 작성 예정 |
| 04 | Vision Transformer (ViT) | 합성곱 없이 이미지의 관계를 학습할 수 있을까? | 향후 작성 예정 |
| 05 | DETR | 객체 탐지를 set prediction 문제로 볼 수 있을까? | 향후 작성 예정 |
| 06 | 자기지도·비전 표현 학습 | 레이블이 적어도 특징을 학습할 수 있을까? | 향후 작성 예정 |

위 항목은 **추천 후보**이지 필수 순서는 아닙니다. 특히 U-Net, ViT, DETR 이후는 관심 분야(분할/탐지/생성 모델/멀티모달)에 따라 분기하는 편이 더 효율적입니다.

## 각 논문을 완료했다고 판단하는 기준

| 확인 사항 | 완료 조건 |
|---|---|
| 논문 독해 | 문제와 기여를 내 말로 3문장 요약 |
| 개념 | 핵심 수식의 기호와 입력·출력 shape 설명 |
| 구현 | 최소 블록 구현 후 테스트 통과 |
| 실험 | 조건과 결과를 재현 가능한 형태로 기록 |
| 비판적 읽기 | 한계 또는 일반화 위험 한 가지 지적 |
