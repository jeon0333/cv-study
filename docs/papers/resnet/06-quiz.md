# 6. 스스로 풀어보는 ResNet 이해도 점검

**사용 방법:** 답을 열기 전에 1~3문장으로 먼저 답을 적어 보세요. 이 페이지는 단순 암기가 아니라 **왜?**라는 질문에 답할 수 있는지 확인하기 위한 것입니다.

## 문제 1. ResNet 이전에 어떤 문제가 관찰되었나요?

깊은 모델에서 무엇이 기대와 달랐는지, **훈련 성능**을 언급해 설명해 보세요.

??? success "정답과 해설"
    층 수를 늘렸는데도 학습이 더 잘되지 않고 오히려 **훈련 오류가 높아지는 degradation problem**이 관찰되었습니다. 이는 모델의 표현력이 충분해도 학습 알고리즘이 좋은 가중치를 찾기 어려울 수 있음을 보여 줍니다.

## 문제 2. Degradation과 과적합은 어떻게 다르죠?

??? success "정답과 해설"
    과적합은 주로 훈련 데이터에는 잘 맞지만 보지 않은 데이터에서는 성능이 나쁜 상황이고, degradation은 더 깊은 모델에서 **훈련 오류부터 더 높아지는 현상**입니다. 두 현상은 공존할 수 있으며 동일한 뜻은 아닙니다.

## 문제 3. `H(x) = F(x) + x`를 설명해 보세요.

`x=3`, `H(x)=8`일 때 `F(x)`는 얼마인가요?

??? success "정답과 해설"
    `F(x)=H(x)-x=5`입니다. 입력 3을 shortcut으로 그대로 보내고, 학습 분기가 만든 5를 더해 8을 출력합니다. 실제 모델에서는 스칼라 숫자 하나가 아니라 텐서 전체에 이 계산을 적용합니다.

## 문제 4. 최적의 함수가 항등 함수라면 잔차는?

??? success "정답과 해설"
    `H(x)=x`이면 `F(x)=0`입니다. 이 경우 잔차 분기가 0에 가까운 변환만 학습하면 입력을 거의 그대로 전달할 수 있습니다. 논문은 이러한 재구성이 최적화를 쉽게 만들 수 있다고 주장합니다.

## 문제 5. Shortcut의 입력과 출력 shape가 다르면?

`x.shape = (4, 64, 32, 32)`이고 잔차 분기가 `(4, 128, 16, 16)`을 출력한다면 어떤 처리가 필요한가요?

??? success "정답과 해설"
    원 입력을 그대로 더하면 shape가 맞지 않습니다. 예를 들어 **`Conv2d(64,128,kernel_size=1,stride=2)`**를 shortcut에 두어 `(4,128,16,16)`으로 맞춥니다. 원 논문에는 projection 외의 shortcut 옵션도 등장합니다.

## 문제 6. ResNet-34와 ResNet-50은 무엇이 다르죠?

??? success "정답과 해설"
    ResNet-34는 **BasicBlock(주로 3×3 Conv 2개)**을, ResNet-50은 **Bottleneck(1×1, 3×3, 1×1 Conv 3개)**을 사용합니다. 두 모델의 stage별 블록 수 배열이 모두 `[3,4,6,3]`일 수 있지만 블록 내부 구조가 다르기 때문에 층 수가 달라집니다.

## 문제 7. Table 2의 수치를 읽어 보세요.

34층 plain의 Top-1 error는 28.54%, ResNet의 error는 25.03%입니다. 오류율의 차이는 얼마이며, **훈련 오류**를 나타낸 표인가요?

??? success "정답과 해설"
    차이는 **3.51%포인트**입니다. Table 2는 **ImageNet 검증 데이터에 대한 Top-1 오류율** 표이며 훈련 오류 표가 아닙니다. 훈련 오류는 Figure 4의 학습 곡선과 함께 해석합니다.

## 문제 8. 실습 결과로 어디까지 주장할 수 있을까요?

랜덤 입력에 대해 `BasicBlock`의 출력 shape가 맞고 `loss.backward()`가 통과했습니다. 'ResNet이 ImageNet에서 더 정확하다'를 증명했다고 말할 수 있나요?

??? success "정답과 해설"
    **아니요.** 이는 코드가 특정 shape에 대해 실행되고 기울기를 계산할 수 있음을 보여 줄 뿐입니다. 이미지 분류 성능과 논문의 ImageNet 결과는 적절한 데이터셋·학습·평가 실험이 필요합니다.
