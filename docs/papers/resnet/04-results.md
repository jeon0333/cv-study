# 4. 논문 결과를 읽는 법: 무엇이 실제로 증명되었을까?

좋은 논문 읽기는 높은 성능 숫자를 암기하는 일이 아닙니다. **저자의 주장과 그것을 지지하는 관측값**, 그리고 **그 실험에서만 적용되는 조건**을 구분하는 일입니다.

## 1. 먼저 비교 조건을 확인하기

아래 값은 원 논문 **Table 2**에 나온 ImageNet validation set의 **Top-1 error(%, 10-crop testing)**입니다.

| 네트워크 | Plain | ResNet | 같은 깊이에서 ResNet의 개선 폭 |
|---|---:|---:|---:|
| 18층 | 27.94 | 27.88 | 0.06%p |
| 34층 | 28.54 | 25.03 | **3.51%p** |

**Top-1 error**는 예측에서 점수가 가장 높은 클래스가 정답과 다른 비율입니다. 낮을수록 좋습니다. **10-crop testing**은 입력 이미지의 여러 잘라낸 영역을 이용해 추론 결과를 집계하는 평가 방식입니다. 단일 이미지 한 번의 예측만으로 얻은 결과와 똑같이 취급하면 안 됩니다.

[출처: 원문 Table 2](https://arxiv.org/pdf/1512.03385#page=5)

## 2. 표에서 추론할 수 있는 것

### 관찰 A. Plain network에서는 깊이가 늘어도 개선되지 않았다

`plain-18 27.94%` → `plain-34 28.54%`이므로, 더 깊은 모델의 검증 오류가 **0.60%p 악화**되었습니다.

### 관찰 B. Residual network에서는 더 깊은 모델이 유리했다

`ResNet-18 27.88%` → `ResNet-34 25.03%`이므로 검증 오류가 **2.85%p 감소**했습니다.

### 관찰 C. 같은 34층에서는 shortcut 구조가 큰 차이를 보였다

`plain-34 28.54%` → `ResNet-34 25.03%`이므로 차이는 **3.51%p**입니다.

!!! info "퍼센트(%)와 퍼센트포인트(%p)를 구분하세요"
    28.54%와 25.03%의 차이는 **3.51%포인트**입니다. 상대적 오류 감소율은 `(28.54 - 25.03) / 28.54 ≈ 12.3%`입니다. 단위를 섞어 표현하지 않도록 주의하세요.

## 3. Figure 4와 함께 읽어야 하는 이유

Table 2는 검증 오류를 보여 줍니다. 논문의 중심 문제인 **degradation이 과적합만이 아니라 최적화 문제라는 주장**은 Figure 4의 **훈련 오류 곡선**과 함께 읽어야 합니다.

논문은 다음과 같이 비교합니다.

- **좌측 그래프(plain network):** 34층 네트워크가 18층 네트워크보다 훈련 오류가 더 높게 유지되는 구간을 관찰합니다.
- **우측 그래프(ResNet):** 잔차 연결이 있는 경우, 34층의 훈련 오류가 더 낮아질 수 있음을 보여 줍니다.

[원문 Figure 4 확인하기](https://arxiv.org/pdf/1512.03385#page=5)

이 결과는 **'shortcut을 넣으면 훈련 최적화가 쉬워질 수 있다'**는 논문의 주장을 뒷받침합니다. 다만 한 연구의 결과가 모든 데이터셋·모델·학습 설정에 자동으로 확장되는 것은 아닙니다.

## 4. Table 3에는 무슨 추가 정보가 있을까?

원문 Table 3에서는 ResNet-34의 shortcut 처리 방식 A/B/C를 비교합니다. 그중 ResNet-34 A는 더 높은 차원에서 zero-padding shortcut을, B는 필요한 곳에 projection shortcut을 사용합니다.

| 실험 | Top-1 error (10-crop, %) | 해석 |
|---|---:|---|
| plain-34 | 28.54 | shortcut이 없는 비교 대상 |
| ResNet-34 A | 25.03 | 차원 증가 시 zero-padding shortcut |
| ResNet-34 B | 24.52 | 차원 증가 시 projection shortcut |
| ResNet-34 C | 24.19 | 모든 shortcut에 projection 사용 |

A와 B/C는 shortcut의 구현과 매개변수 수가 다르므로 **완전히 동일한 조건에서 오로지 덧셈 하나만 바꾼 실험**이라고 단정하면 안 됩니다. 논문은 옵션 A에서도 개선이 나타난다는 점을 중요하게 봅니다.

[원문 Table 3 확인하기](https://arxiv.org/pdf/1512.03385#page=6)

## 5. 논문에 대한 비판적 질문

다음 질문을 확인하면 논문을 더 깊게 읽을 수 있습니다.

1. 비교 모델의 학습 스케줄, 데이터 전처리, 파라미터 수는 얼마나 유사한가?
2. 18층과 34층 외의 경우에도 같은 관찰이 성립하는가?
3. 무작위 초기값이나 학습률을 바꿔도 결과가 유지되는가?
4. 분류가 아닌 탐지·분할에서도 유사한 효과가 나타나는가?
5. 연산량과 메모리 사용량은 얼마인가?

저자들은 ImageNet뿐 아니라 CIFAR-10에서도 실험하고, 더 깊은 모델 및 탐지 문제로 활용 범위를 넓힙니다. 그러나 학습자가 **자기 실험을 통해 검증한 사실**과 **논문에서 보고한 사실**은 반드시 분리해야 합니다.
