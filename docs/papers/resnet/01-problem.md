# 1. 왜 네트워크를 깊게 하면 훈련이 더 어려워질까?

## 이 페이지에서 답할 질문

**Q. 층을 더 쌓으면 더 복잡한 함수를 표현할 수 있을 텐데, 왜 34층 모델이 18층 모델보다 성능이 나쁠 수 있을까요?**

이 질문은 ResNet 논문의 출발점입니다. 바로 해결책으로 넘어가지 말고, 먼저 무엇이 예상과 달랐는지 보겠습니다.

## 1. 직관: 더 많은 도구와 더 쉬운 작업은 다르다

그림을 그리는 사람이 연필 한 자루를 가졌을 때보다 여러 가지 도구를 가지면 **표현할 수 있는 범위**는 늘어납니다. 하지만 도구를 많이 사용해야 하는 작업이 항상 더 **쉬운 작업**이 되는 것은 아닙니다.

신경망도 비슷합니다.

- **표현력:** 충분한 가중치를 적절히 선택한다면 얼마나 다양한 함수를 표현할 수 있는가?
- **최적화:** 실제 학습 과정이 좋은 가중치를 찾아낼 수 있는가?

더 깊은 모델은 표현력이 커질 수 있어도, 학습 알고리즘이 좋은 해를 찾기 더 어려울 수 있습니다.

## 2. 논문이 관찰한 것: Degradation Problem

**성능 저하 문제(degradation problem)**란 더 깊은 모델에서 성능이 포화된 뒤 오히려 떨어지고, 특히 **훈련 오류(training error)까지 증가할 수 있는 현상**입니다.

??? info "과적합과 왜 다른가요?"
    과적합에서는 훈련 데이터를 잘 맞추면서 검증/테스트 데이터에 대한 성능이 나빠지는 일이 대표적입니다. ResNet 논문은 **훈련 데이터의 오류 자체가 더 높은 상황**을 지적합니다. 그래서 단지 일반화의 문제가 아니라 **최적화 문제**가 핵심이라고 봅니다.

논문의 Figure 1에는 CIFAR-10에서 20층과 56층 **plain network**의 훈련 오류와 테스트 오류가 나타납니다. 'Plain'은 shortcut이 없는 일반적인 계층 쌓기 구조를 말합니다. 더 깊은 56층 모델의 **훈련 오류가 더 높은** 결과를 보여 줍니다.

[논문 PDF p.1의 Figure 1 확인하기](https://arxiv.org/pdf/1512.03385#page=1)

## 3. 숫자 확인: ImageNet 결과의 단서

논문 Table 2에 제시된 ImageNet 검증 데이터의 **Top-1 오류율(%, 10-crop 평가)**입니다.

| 모델 깊이 | Plain network | ResNet |
|---|---:|---:|
| 18층 | 27.94% | 27.88% |
| 34층 | 28.54% | 25.03% |

이 표에서 **plain network**끼리 비교하면 `18층 27.94%`에서 `34층 28.54%`로 오류율이 **0.60%p 증가**했습니다. 깊어졌지만 검증 지표가 오히려 악화된 것입니다.

여기서 중요한 구분이 있습니다.

- **Table 2 자체는 검증 오류율**을 기록한 표입니다.
- **훈련 오류가 증가했다는 직접적인 증거**는 같은 논문의 **Figure 4에 나타난 학습 곡선**에서 확인합니다.

따라서 Table 2를 곧바로 '훈련 오류 표'라고 부르면 부정확합니다.

## 4. 저자들이 제시한 논리

18층 네트워크가 어떤 유용한 함수를 이미 학습했다고 해봅시다. 34층 모델에 추가된 계층들이 **입력을 그대로 통과시키는 항등 함수(identity mapping)**를 구현할 수 있다면, 적어도 기존 18층 모델의 결과를 흉내 내는 해가 존재합니다.

따라서 수학적으로는 더 깊은 모델에 좋은 해가 **있을 수 있습니다**. 하지만 실제 SGD 학습이 그 해를 잘 찾는지는 다른 문제입니다.

이 논리가 ResNet 아이디어로 이어집니다. **추가 계층들이 항등 함수를 직접 구현해야 한다면 어려울 수 있으니, 처음부터 입력을 그대로 전달하는 경로를 만들어 두면 어떨까요?**

## 5. 무엇을 주장하지 않는가?

!!! warning "주의해야 할 해석"
    - ResNet이 모든 깊은 네트워크의 학습 문제를 완전히 해결한 것은 아닙니다.
    - 이 논문이 관찰한 degradation을 모두 **vanishing gradient** 한 가지 원인으로 단정하지 않습니다. 저자들은 자신들의 실험 설정에서 BN과 gradient norm을 근거로 그렇게 보지 않는다고 논의합니다.
    - 깊이가 증가할 때 언제나 오류가 더 낮아져야 한다는 실험적 법칙을 주장하는 것도 아닙니다.

**문제 2.** Degradation과 과적합을 한 문장씩 구분해 보세요.

??? success "답 예시"
    Degradation은 더 깊은 모델에서 **훈련 자체가 잘되지 않아** 훈련 오류가 커지는 현상이고, 과적합은 훈련 데이터에 비해 **새로운 데이터**에서 성능이 나빠지는 현상입니다. 실제 실험에서는 두 요인이 함께 나타날 수도 있습니다.
