# 용어 사전

읽다가 의미가 흐릿해지면 이 페이지로 돌아오세요. 처음에는 쉬운 뜻을 이해하고, 이후 각 단원에서 정확한 기술적 정의를 연결하는 방식으로 공부하면 됩니다.

| 용어 | 쉬운 한국어 뜻 | 이 사이트에서 중요한 이유 |
|---|---|---|
| **Batch** | 한 번에 처리하는 데이터 묶음 | 텐서의 첫 축 `N` |
| **Batch Normalization (BN)** | 중간 활성값을 정규화하는 층 | 깊은 네트워크 학습 안정화에 도움 |
| **Channel** | 같은 공간 위치의 서로 다른 특징 종류 | Conv 입력·출력 shape 이해 |
| **Convolution** | 작은 필터로 주변을 살펴 특징을 계산 | CNN·ResNet의 기본 연산 |
| **Cross-Entropy Loss** | 분류 모델이 정답에 얼마나 부합하는지 재는 손실 | 분류 학습 목표 |
| **Degradation Problem** | 깊게 만들었는데 훈련 성능까지 더 나빠지는 문제 | ResNet의 출발점 |
| **Feature Map** | 모델이 계산한 특징 지도 | 합성곱 결과 |
| **Gradient** | 값을 조금 바꿀 때 손실이 변하는 정도와 방향 | 가중치 학습의 핵심 신호 |
| **Identity Mapping** | 입력을 그대로 출력하는 함수 | `H(x)=x`가 뜻하는 것 |
| **Kernel** | 합성곱에 쓰는 작은 숫자 필터 | 국소 특징 추출 |
| **Logit** | softmax 이전의 클래스 점수 | 모델의 최종 출력 |
| **Optimization** | 손실이 작아지는 가중치를 찾아가는 과정 | '좋은 해 존재'와 '찾을 수 있음' 구분 |
| **Overfitting** | 훈련 데이터에 지나치게 맞추는 현상 | degradation과 혼동 방지 |
| **Padding** | 경계 주변에 값을 채우는 것 | 출력 공간 크기 조절 |
| **Projection Shortcut** | 입력 경로에도 학습 가능한 변환을 적용한 지름길 | shape가 다를 때 합치기 |
| **ReLU** | 음수는 0, 양수는 그대로 두는 함수 | 비선형성 도입 |
| **Residual Mapping** | 입력에 더할 '변화량'을 출력하는 함수 | ResNet 핵심 `F(x)` |
| **Shortcut/Skip Connection** | 일부 층을 건너뛰어 정보를 전달하는 경로 | 잔차 학습 구조 만들기 |
| **Stride** | 필터가 이동하는 보폭 | 특징 맵 크기 조절 |
| **Tensor** | 여러 차원으로 배열된 숫자 | 이미지·특징·가중치 표현 |
| **Top-1 Error** | 가장 점수가 높은 예측이 틀린 비율 | 논문 표의 평가 지표 |
| **Validation Set** | 학습 설정을 점검하는 별도 데이터 | 테스트와 혼동 방지 |

**추천:** 한 번에 모두 외우려 하지 말고, [ResNet 단원](papers/resnet/index.md)에서 만난 용어만 그때그때 확인하세요.
