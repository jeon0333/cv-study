# 실험 기록: 결과보다 과정이 먼저입니다

논문 구현에서 중요한 것은 '정확도가 몇 % 나왔다' 하나가 아닙니다. **어떤 조건에서 어떤 결과가 나왔는지**, 그리고 다른 사람이 **같은 설정을 재현할 수 있는지**를 남기는 일이 중요합니다.

## 실험 노트 필수 항목

| 항목 | 예시 |
|---|---|
| 실험의 질문 | shortcut이 있는 모델과 없는 모델의 최적화가 어떻게 다른가? |
| 모델 구조 | TinyResNet / stage당 블록 수 / shortcut 종류 |
| 데이터 분할 | train/validation/test 구분, 샘플 수 |
| 전처리 | 정규화, augmentation |
| 학습 설정 | seed, optimizer, batch size, epochs, learning rate |
| 평가 지표 | 훈련 손실, 훈련 정확도, 검증 정확도 |
| 실행 환경 | CPU/GPU, PyTorch 버전 |
| 관찰 | 그래프 또는 로그의 특징 |
| 해석 | 가설이 지지되는지, 다른 설명은 없는지 |
| 제한 | 실험의 규모와 한계 |


!!! warning "재현 가능한 비교의 기본"
    두 모델을 비교할 때는 동일한 데이터 분할, 유사한 학습 예산, 같은 평가 기준을 사용해야 합니다. 평가만을 위한 test 데이터를 모델 선택 과정에 반복 활용하지 않는 것도 중요합니다.
