# CNN 기초: 이미지는 텐서이고, 합성곱은 특징을 찾는다

## 오늘의 목표

1. 이미지와 특징 맵(feature map)이 어떤 숫자 배열인지 설명한다.
2. 합성곱(Convolution), 채널(Channel), 커널(Kernel)의 의미를 구분한다.
3. PyTorch에서 입력과 출력의 **shape(차원 크기)**를 계산한다.

## 1. 직관: 작은 창으로 이미지를 살펴보기

이미지가 있다고 가정합시다. 전체를 한 번에 해석하기보다 **작은 창을 한 칸씩 이동**하면서 모서리, 선, 질감 같은 패턴이 있는지 검사하면 어떨까요? 합성곱 신경망(CNN)은 비슷한 일을 여러 계층에서 반복합니다.

여기서 사용하는 작은 숫자 표가 **커널(kernel)**이고, 커널로 이미지의 국소 영역을 처리해 얻은 출력 숫자 지도가 **특징 맵(feature map)**입니다. CNN의 커널 값은 사람이 고정해 두는 것이 아니라 보통 학습 과정에서 조정됩니다.

### 알아둘 용어

| 용어 | 쉬운 뜻 | 역할 |
|---|---|---|
| Tensor(텐서) | 여러 차원으로 배열된 숫자 | 이미지·가중치·출력을 담는 자료 구조 |
| Channel(채널) | 같은 위치에서 다른 종류의 값 | RGB의 3색 채널 또는 학습된 특징 |
| Kernel(커널) | 주변 값을 함께 보는 작은 필터 | 지역 패턴 추출 |
| Stride(스트라이드) | 커널이 한 번에 이동하는 칸 수 | 출력 공간 해상도 조정 |
| Padding(패딩) | 이미지 테두리 주변에 숫자 추가 | 가장자리 처리와 출력 크기 조정 |

## 2. 숫자로 생각하기

입력이 한 채널의 3×3 이미지이고, 커널이 2×2라고 해봅시다.

```text
입력                  커널
1 2 0                 1 0
0 1 3                 0 1
2 1 1
```

첫 번째 위치에서 값들을 원소별로 곱하고 더하면 `1×1 + 2×0 + 0×0 + 1×1 = 2`입니다. 한 칸씩 이동해 나머지 값을 계산합니다. 딥러닝 프레임워크의 `Conv2d`는 엄밀히 말하면 커널을 뒤집지 않는 **상호상관(cross-correlation)** 형태지만, 관례적으로 convolution이라고 부릅니다.

## 3. 이미지 shape 읽기

PyTorch에서 일반적인 이미지 배치의 shape는 **`(N, C, H, W)`**입니다.

- `N`: 한 번에 처리하는 이미지 개수 (batch size)
- `C`: 채널 수 (RGB라면 3)
- `H`: 이미지 높이
- `W`: 이미지 너비

예를 들어 `(8, 3, 32, 32)`는 32×32 RGB 이미지 8장을 담은 텐서입니다.

다음 코드의 출력 shape를 먼저 예상해 보세요.

```python
import torch
from torch import nn

x = torch.randn(8, 3, 32, 32)
conv = nn.Conv2d(in_channels=3, out_channels=16,
                 kernel_size=3, stride=1, padding=1)
y = conv(x)
print(y.shape)  # torch.Size([8, 16, 32, 32])
```

입력 채널 3개를 사용해 **출력 특징 16종류**를 만들었으므로 출력 채널은 16이 됩니다.

## 4. 출력 높이 계산

팽창(dilation) 정도까지 포함한 일반적인 공식은 다음과 같습니다.

\[
H_{out} = \left\lfloor \frac{H_{in} + 2P - D(K-1) -1}{S} + 1 \right\rfloor
\]

`P`는 padding, `K`는 커널 크기, `S`는 stride, `D`는 dilation입니다. 처음에는 `D=1`로 생각하면 됩니다.

예: `H=32, K=3, P=1, S=2`이면 출력 높이는 `16`입니다. 너비도 같은 방식으로 계산합니다.

## 5. ResNet 전에 꼭 연결할 개념

CNN 계층을 더 쌓으면 더 복잡한 변환을 표현할 **가능성**이 생깁니다. 그러나 계층 수가 많아진다고 자동으로 학습이 쉬워지지는 않습니다. 다음 단원에서 이 차이를 설명합니다.

!!! warning "흔한 오해"
    **필터 개수 = 이미지 크기**가 아닙니다. 필터 개수는 출력 **채널 수**를 결정하고, stride·padding·kernel 크기는 출력 **공간 크기**를 결정합니다.

### 확인 문제

`(4, 16, 32, 32)` 입력에 `Conv2d(16, 32, 3, stride=2, padding=1)`을 적용하면 출력 shape는 무엇일까요?

??? success "정답 확인"
    `(4, 32, 16, 16)`입니다. 배치 4는 유지되고, 출력 채널은 32, 공간 크기는 절반으로 바뀝니다.
