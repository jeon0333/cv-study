# 최적화와 역전파: 왜 깊다고 무조건 좋은 것은 아닐까?

## 목표

ResNet 논문에서 등장하는 **훈련 오류(training error)**, **일반화(generalization)**, **기울기(gradient)**, **성능 저하(degradation)**를 구분합니다.

## 1. 문제·입력·출력·모델 역할

이미지 분류 모델은 이미지를 입력받아 여러 클래스의 점수(로짓)를 출력합니다. 학습은 정답과 예측의 차이를 측정하는 **손실 함수(loss function)**가 작아지도록 모델 가중치를 바꾸는 과정입니다.

| 요소 | 이미지 분류 예시 |
|---|---|
| 문제 | 이미지가 어떤 물체인지 분류하기 |
| 입력 | 이미지 텐서 `(N, 3, H, W)` |
| 출력 | 클래스별 점수 `(N, 클래스 수)` |
| 모델 역할 | 이미지를 점수로 바꾸는 함수 만들기 |
| 학습 목표 | 주어진 훈련 데이터에서 손실을 최소화하기 |
| 주의 | 훈련 손실이 작더라도 새 이미지에 잘 맞는지는 별도 문제 |

## 2. Gradient란?

**기울기(gradient)**는 '이 가중치를 아주 조금 바꾸면 손실이 어느 방향으로 얼마나 변하는가?'를 알려주는 수치입니다. **역전파(backpropagation)**는 출력에서 출발하여 연쇄법칙(chain rule)으로 각 층의 기울기를 계산합니다.

작은 예로 손실이 \(L(w)=(w-3)^2\)이면 기울기는 \(2(w-3)\)입니다. `w=1`일 때 기울기는 `-4`입니다. 경사하강법은 음의 기울기 방향으로 가중치를 업데이트하므로 `w`를 증가시키는 쪽으로 움직입니다.

## 3. 꼭 구분해야 할 세 가지 현상

| 현상 | 무엇이 관찰되는가? | 구분 포인트 |
|---|---|---|
| 과적합(overfitting) | 훈련 데이터에서는 잘 되지만 새로운 데이터에서는 나빠짐 | 훈련 성능과 검증 성능 사이의 차이 |
| 기울기 소실(vanishing gradient) | 앞쪽 계층으로 전달되는 기울기가 매우 작아질 수 있음 | 학습 신호의 크기 문제 |
| 성능 저하(degradation) | 깊이를 더했는데 **훈련 오류 자체가** 커짐 | 최적화의 어려움을 드러내는 현상 |

ResNet 논문은 단순히 과적합 문제가 아니라 **훈련 오류가 더 높아지는 현상**에 주목합니다. 저자들은 사용한 설정에서 Batch Normalization과 기울기 측정을 근거로, 이것을 단순한 기울기 소실만으로 설명하기 어렵다고 논의합니다.

## 4. 왜 더 깊은 모델은 적어도 같아야 할 것처럼 보일까?

기존 모델이 잘 작동하고 있는데 새로운 층을 추가한다고 상상해 봅시다. 새 층이 **입력을 그대로 통과시키는 항등 함수(identity function)**만 수행한다면 기존 모델과 같은 결과를 만들 수 있습니다.

따라서 이론적으로 '기존 해를 복사하고 추가 계층을 항등 함수로 두는 해'가 존재할 수 있습니다. 그런데 일반적인 깊은 네트워크는 실제 학습 과정에서 그 해를 쉽게 찾지 못할 수 있습니다. **표현할 수 있는 능력**과 **학습해서 찾아내는 능력**은 다르기 때문입니다.

!!! note "핵심"
    **더 높은 표현력(capacity)**이 곧 **더 쉬운 최적화(optimization)**를 보장하지는 않습니다. ResNet은 이 차이를 다루는 논문입니다.

## 5. 확인 문제

실험 A에서 훈련 오류는 낮지만 검증 오류가 높습니다. 실험 B에서 더 깊은 모델이 얕은 모델보다 훈련 오류부터 높습니다. 각각 무엇을 의심해야 할까요?

??? success "정답"
    실험 A에서는 과적합 가능성을, 실험 B에서는 최적화 난이도와 논문에서 말하는 **degradation problem**을 검토합니다. 물론 하나의 지표만 보고 원인을 단정할 수는 없습니다.
